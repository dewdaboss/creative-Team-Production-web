# हिन्दी परियोजना — 'कफ़न' कहानी में चित्रित समस्याओं का विस्तृत विश्लेषण

महाविद्यालयीन स्तर (B.A. / B.Com / BBA आदि) के हिन्दी परियोजना कार्य के लिए तैयार सामग्री।

## फ़ाइलें

| फ़ाइल | विवरण |
| --- | --- |
| `kafan-project.pdf` | **मुख्य डिलीवरेबल** — 12 पृष्ठ का तैयार प्रोजेक्ट (आवरण, आभार, विषय-सूची, 14 अध्याय, परिशिष्ट) |
| `kafan-project.md` | वही सामग्री सादे पाठ में — हाथ से लिखने या कॉपी-पेस्ट करने के लिए |
| `content.py` | पूरा पाठ (एक ही स्रोत — PDF और Markdown दोनों इसी से बनते हैं) |
| `build_pdf.py` | PDF + Markdown बनाने की स्क्रिप्ट |

## PDF में क्या है (12 पृष्ठ)

1. आवरण पृष्ठ (नाम, कक्षा, मार्गदर्शक के लिए खाली स्थान)
2. आभार + विषय-सूची + परियोजना-विवरण
3. प्रस्तावना · प्रेमचंद का जीवन परिचय
4. रचना-पृष्ठभूमि · कथासार
5. पात्र-परिचय
6–8. **चित्रित समस्याएँ** — गरीबी, जातिगत भेदभाव, सामंतवाद/शोषण, अंधविश्वास-पाखंड,
   नैतिक पतन, स्त्री-जीवन, स्वास्थ्य-शिक्षा, सामाजिक सुरक्षा, संवेदना का ह्रास
9–10. शीर्षक व प्रतीक, शिल्प-भाषा, प्रमुख उद्धरण, समाधान-सुझाव, प्रासंगिकता, निष्कर्ष
11–12. सहायक ग्रंथ सूची + परिशिष्ट (12 अभ्यास प्रश्न-उत्तर)

कुल पाठ लगभग **5,500 शब्द** — जो 10–15 पृष्ठ की सामान्य आवश्यकता से मेल खाता है।

## दोबारा बनाने का तरीका

```bash
pip install fpdf2 uharfbuzz fonttools
python3 build_pdf.py
```

पहली बार चलाने पर Noto Serif/Sans Devanagari फ़ॉन्ट स्वचालित रूप से `.fonts/` में
डाउनलोड हो जाते हैं (यह फ़ोल्डर git में नहीं जाता)।

## बदलाव कैसे करें

* पाठ बदलना है → `content.py` में सम्बंधित अनुच्छेद बदलें, फिर स्क्रिप्ट चलाएँ।
* फ़ॉन्ट आकार/लाइन-स्पेसिंग → `build_pdf.py` में `BODY_SIZE`, `BODY_LH`।
* विषय-सूची के पृष्ठ-संख्या स्वतः गणना होते हैं (दो-चरणीय बिल्ड)।
